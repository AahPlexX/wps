# Product requirements

## Product scope

World Political Structures is a GitHub Pages reference site at `aahplexx.github.io/wps`. It converts the validated standalone political-structure directory and 3D globe into a maintainable Vite + TypeScript + React + Tailwind CSS application with JSON-backed data.

## Requirements

| ID | Requirement | Acceptance test |
| --- | --- | --- |
| WPS-001 | The political dataset contains exactly 195 unique sovereign-state records in one shared JSON source. | `npm run validate:data` proves 195 unique records with the complete schema. |
| WPS-002 | The homepage provides a searchable, filterable directory of all country records. | Search, assignment, structure, and grouping controls update visible results from the shared dataset. |
| WPS-003 | Directory state is deep-linkable. | Search/filter/group state round-trips through URL query parameters and back/forward navigation. |
| WPS-004 | Countries are alphabetical within each visible group and political-assignment groups use the defined order. | Focused unit test proves deterministic grouping and alphabetical order. |
| WPS-005 | The directory reflows without horizontal page overflow on phones while preserving all four data fields. | Browser QA at 390px shows country records with country, top office, structure, and hierarchy present. |
| WPS-006 | A separate `/wps/map/` page provides an interactive 3D orthographic world globe. | Pointer drag, wheel zoom, keyboard rotation/zoom, reset, country search, and country selection work in browser QA. |
| WPS-007 | Selecting a map country shows the same political facts used by the directory and deep-links the selected country. | Country detail is read from `src/data/countries/*.json`; `?country=` selects and restores the same state. |
| WPS-008 | All 195 states remain selectable on the globe even when 1:110m source geometry omits a visible polygon. | `npm run validate:data` proves 195 map targets and exactly 29 point targets for polygon-absent small states. |
| WPS-009 | Canvas interaction has an accessible HTML equivalent. | Country search and semantic HTML details expose the selected data without requiring canvas perception or pointer input. |
| WPS-010 | The UI follows WCAG 2.2 AA interaction basics: visible focus, semantic controls, minimum target sizing, skip links, zoom support, reduced-motion handling, and no focus-obscuring overlays. | Browser/accessibility review plus stylesheet/markup inspection passes. |
| WPS-011 | Public pages contain no external source links or citation UI. | Production DOM/link audit finds only internal navigation. |
| WPS-012 | The client has no external runtime data or visualization dependency. | Production bundle uses local JSON and Canvas 2D; network-independent render succeeds after assets load. |
| WPS-013 | The implementation uses Vite, TypeScript, JSON, React, and Tailwind CSS with exact top-level package versions. | `package.json`, lockfile, and production build prove the stack. |
| WPS-014 | GitHub Pages builds from `main` with Vite base `/wps/`. | Deployment workflow builds `dist`, publishes the Pages artifact, and the live `/wps/` and `/wps/map/` routes load. |
| WPS-015 | Repository documentation stays resumable at every stop. | `TRACKER.md` and `TASKS.md` contain current “Resume here” entries and fresh evidence. |
| WPS-016 | The established constitutional-field-guide visual system is preserved across directory and map surfaces. | `DESIGN.md` tokens match the implemented palette/type/layout and browser screenshots show one coherent system. |
| WPS-017 | The map country search provides an accessible starts-with typeahead from the first typed character. | Focused matcher test passes; browser QA proves one-character live filtering, keyboard/pointer selection, and preserved `?country=` deep-link behavior. |
| WPS-018 | Already-open clients detect a newer deployed WPS version and offer an accessible update modal showing the available version with only `Update` and `Cancel` actions. | Focused version tests plus live browser QA prove a synthetic newer manifest opens the dialog on directory and map routes; Update reloads, Cancel session-dismisses that exact version, later versions can prompt, and real same-version deployments do not prompt. |
| WPS-019 | `package.json` is the authoritative application version; versioning starts at `1.0.0`, and every significant product update increments the patch component by exactly one (`+0.0.1`). | The release commit increments this significant update to `1.0.1`; Vite embeds the package version and emits the identical value in `dist/version.json`, with package-lock root version kept in sync. |
| WPS-020 | User-driven directory state changes and map country selections create meaningful browser-history entries, and browser back/forward restores the corresponding URL and visible state without writing a replacement history entry. Consecutive directory-search keystrokes within one focus/edit session share one history entry so Back does not step through every character. | Focused history-policy tests pass; live browser QA proves a directory filter change and a map country selection increase history length, Back restores the previous URL/UI state, Forward restores the changed state, and one contiguous search edit session creates only one additional history entry. |
| WPS-021 | The deployed directory and map preserve valid WCAG 2.2 A/AA landmark and ARIA semantics, and the directory reflows at 200% zoom without page-level horizontal scrolling while its wide data table remains scrollable within its own container. | Independent live accessibility scans report no duplicate-banner, prohibited-ARIA, unlabeled-complementary-landmark, or 200%-zoom page-overflow failures; a 720px CSS-viewport browser audit proves document `scrollWidth <= clientWidth` while `.table-wrap` keeps the table’s scoped horizontal overflow. |
| WPS-022 | The map country typeahead keeps DOM focus on the editable combobox while its listbox is open; popup options are excluded from the page Tab sequence, and existing Arrow-key, Enter, pointer, and deep-link selection behavior remains available. | Current WAI-ARIA APG combobox guidance plus live browser QA prove visible options have `tabIndex=-1`, the combobox retains DOM focus while `aria-activedescendant` tracks the active option, Enter commits the active country, pointer selection still commits, and Tab proceeds to the next page control instead of entering or collapsing through a popup option. |
| WPS-023 | Every client-facing WPS surface follows the repository-wide responsive UI standard: layout is driven by available space, preserves information/function across supported viewport sizes, input methods, zoom/text enlargement, safe areas, long strings and RTL, and contains necessary two-dimensional table/map behavior without making the page scroll in two dimensions. | `docs/RESPONSIVE_UI.md` encodes the invariant; `npm run validate` passes; live browser red→green QA covers both routes at 320px width, the map at 256px height, 200% text including 320px+200% together, representative intermediate/wide sizes, RTL/long-string stress, and affected keyboard/pointer behavior with no unintended page-level horizontal overflow or clipped/obscured required controls/instructions. |
| WPS-024 | The Myanmar record reflects the verified post-2026 operative national structure: a military-backed presidency rather than the obsolete commander-in-chief-led executive chain. | A focused data regression test proves Myanmar is grouped under `President / co-president`, uses `President` as the assignment, identifies a military-backed presidential government, starts the hierarchy with the President and Vice Presidents / Cabinet, and contains no obsolete Commander-in-Chief-first hierarchy; repository validation and live directory/map smoke checks pass. |
| WPS-025 | The directory ignores unsupported controlled URL-filter values so malformed deep links cannot silently apply hidden category, structure, or grouping state that disagrees with the visible controls. Valid directory query/filter/group values continue to round-trip unchanged. | A focused parser regression test proves unknown category/structure/group values normalize to the visible defaults while preserving free-text search; live browser QA proves a malformed deep link shows default controls and the unfiltered result set with no page overflow, while an existing valid deep link still restores its intended state. |
| WPS-026 | A dedicated `/wps/compare/` client page lets users select up to four unique sovereign states from the shared dataset and compare their top political assignment, government structure, category, hierarchy, and explanatory note. Committed selections are deep-linkable through repeated `country=` query parameters; unknown and duplicate parameters are ignored, order is preserved, one-country prefills are allowed, and two or more countries render the comparison. | Focused comparison-state tests prove ordered validation, de-duplication, the four-country cap, and URL round-trip behavior; production build includes `/wps/compare/`; live browser QA proves keyboard/pointer add/remove, Back/Forward restoration, valid one-country prefill, 2–4-country comparison, and responsive containment at 320px + 200% text, representative intermediate/wide sizes, RTL/long-content stress, and the shared navigation on all three routes. |
